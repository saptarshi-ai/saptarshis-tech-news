# Saptarshi Tech Hub automation

A personal automation run by Saptarshi Sengupta. It drafts LinkedIn posts for the Saptarshi Tech Hub company page using n8n and Google Gemini. A Google Sheet holds the post queue, and Gmail sends each draft to the owner for approval before anything is published.

This app is used only by its owner. It is not offered to the public.
